# Market Configuration Boundary

Milwaukee is the first intended pilot. Later markets should be introduced through a shared, validated configuration contract rather than copied code, copied applications, or separate repositories.

A future authorized task may define identifiers, geography, source vintages, parameters, and safe references needed by market configuration. This document does not invent or accept that final schema.

Never commit real confidential seed points, live candidate locations, pursuit details, or internal direction in market configuration. Use ignored local overlays or approved secret/configuration mechanisms when later authorized.
