# Sprouts Customer Geography

Sprouts Customer Geography is public-data decision support for understanding likely Sprouts-oriented household geography. It is not a final site-selection engine, Sprouts' proprietary customer model, an Esri Tapestry reproduction, or Site Scanner. Milwaukee is the pilot; later markets are configuration-driven rather than copied applications.
