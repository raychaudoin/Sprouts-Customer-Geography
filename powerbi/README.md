# Power BI Boundary

Power BI is the intended MVP presentation environment. It should consume stable, prepared outputs while complex GIS calculations, source normalization, feature engineering, uncertainty, and quality logic remain in a reproducible upstream analytical layer.

Future authorized Power BI work should prefer a source-control-friendly project representation when available, supportable, and approved. It must document the report, semantic-model, data-contract, refresh, and any binary fallback sources of truth so the report can be reconstructed and governed.

The repository assumes neither Microsoft Fabric, Power BI Service, premium capacity, ArcGIS organizational access, organizational publishing rights, nor approval for custom visuals. A functional local MVP path must remain possible, and presentation definitions must not be coupled to one proprietary source or committed confidential overlay.

No Power BI report or project was created during GOV-01.
